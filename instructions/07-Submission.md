# Submission

--------------
* What to submit:  Make sure all Cucumber scenarios are passing.  A shorthand way to run all of them is `cucumber features/` which runs all `.feature` files in the given directory.
* Paste the link to your Render app (e.g. `https://<name>.onrender.com`) in the text file to the left. This link will likely be the work of just 1 of your teammates, however, the expectation is that each teammate completed the assignment locally and one member simply deployed their assignment to Render for the group's convenience.
* On Gradescope, submit your whole app together with `sinatra-url.txt`: a zip of your repo, or the files themselves, including `app.rb`, `config.ru`, `lib/wordguesser_game.rb` and `views/`. The autograder runs the tests twice, once against your deployed app and once against the code you submitted (which it starts itself), and each test is worth half its points in each run. A missing deployment, or a repo that will not start, therefore costs you only that half.
